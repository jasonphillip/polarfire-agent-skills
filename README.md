# PolarFire Agent Skills

This pack gives a coding agent a staged workflow and evidence rules for model deployment on the Microchip PolarFire SoC.
It targets the MPFS250T kit and CoreVectorBlox V250.
Optional skills cover fabric control and programming.

## Quick Start

Read `docs/install.md` for client setup and tested discovery claims.
Create the kit environment and run the small local inspect path:

```sh
KIT_ROOT=/absolute/path/to/polarfire-agent-skills
make -C "$KIT_ROOT" env
"$KIT_ROOT/.venv/bin/python" -m pfkit example run signal-freq --until inspect --run-dir "$KIT_ROOT/reports/signal-inspect"
```

The inspect stage needs the Python environment and example inputs.
Compile and sim need a configured tools host.
Infer needs a configured kit and built `hw/vbx_run`.
Each stage writes evidence in its run directory.

Validated: clean Linux and macOS inspect runs, client workflows, simulator
checks, and 64-sample kit runs. See `docs/validation.md`.
The kit's Libero build completed on 2026-10-12: timing met and the job was
exported (`evidence/2026-10-12-libero-build/`). That image has not been
programmed or tested on a kit. Hardware evidence uses the earlier case-study
image. The new `--samples 64` CLI route has not run on the kit; its input
payloads were regenerated byte for byte on the host
(`evidence/2026-10-13-release-readiness/payload-regeneration.md`).
See `docs/validation.md` and `docs/release-notes.md`.

This is a PolarFire-specific integration of the VectorBlox flow with evidence
handling. Prior art includes FINN's end-to-end flow and verification methods,
and the hls4ml Libero backend. The hls4ml PR below was an open draft as of
2026-10-13; nothing from it was accepted upstream at that review. Its current
state was not checked in this offline documentation pass.
